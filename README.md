# Task Manager App

Este es un proyecto de prueba que simula cómo se trabaja en una empresa de desarrollo de software, con una arquitectura Frontend + Backend.

## 📦 Estructura

- `/backend`: API REST en Node.js + Express
- `/frontend`: Interfaz de usuario generada en V0.dev (React)
- `/docs`: Documentación técnica (API, diseño)

## 🚀 Primeros pasos

```bash
git clone https://github.com/tu-usuario/task-manager-app.git
cd backend
npm install
npm run dev
